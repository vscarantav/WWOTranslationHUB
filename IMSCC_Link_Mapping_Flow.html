Link mapping process

How extracted course files are scanned, normalized, mapped from the shared store, resolved by the user when necessary, written back into the IMSCC workspace, and represented in the final translation report.

Automated User decision Persistent data Successful output Stop condition 
flowchart TD
    START([IMSCC extracted into workspace]) --> PREP[Prepare approved special-page content]
    PREP --> COLLECT[Collect package files]
    COLLECT --> INIT[Initialize LinkProcessor with target language]
    INIT --> LOAD[(Load app/link_mapping.json)]
    LOAD --> FILE{More package files?}

    FILE -- No --> TRANSLATE[Continue into file translation]
    TRANSLATE --> LINK_CLEAN[Per-file cleanup: unwrap Google redirects and remove obsolete LTI redirect icons]
    LINK_CLEAN --> CHURCH_POST[After translation, enforce target language on Church links]
    CHURCH_POST --> REPORT[Build Link Actions and optional Commented Links report tabs]
    REPORT --> DONE([Translated IMSCC and report])

    FILE -- Yes --> TYPE{HTML, HTM, XML, QTI, or TXT?}
    TYPE -- No --> FILE
    TYPE -- Yes --> READ[Read file and derive human-readable page title]
    READ --> SCAN[Scan href values, XML/QTI url elements, and bare HTTP URLs]
    SCAN --> URL{More URLs in this file?}
    URL -- No --> WRITE{Did content change?}
    WRITE -- Yes --> SAVE_FILE[Write updated content to workspace file]
    WRITE -- No --> FILE
    SAVE_FILE --> FILE

    URL -- Yes --> NORMALIZE[HTML-unescape URL and normalize Google account or redirect forms]
    NORMALIZE --> IGNORE{Ignored namespace, Canvas backend or file URL?}
    IGNORE -- Yes --> KEEP[Keep URL unchanged]

    IGNORE -- No --> OBSOLETE{Known obsolete tool link?}
    OBSOLETE -- Yes --> LOG_OBSOLETE[Log FIX EN Course action]
    LOG_OBSOLETE --> KEEP

    OBSOLETE -- No --> AUTO{Automatic localization rule applies?}
    AUTO -- Yes --> AUTO_REPLACE[Localize Church scripture lang or PT course repository path]
    AUTO_REPLACE --> REPLACE[Replace URL in working content]

    AUTO -- No --> MAPPED{Source URL has a target-language mapping?}
    MAPPED -- Yes --> STORED[(Read localized URL from mapping store)]
    STORED --> LOG_MAP[Log MappedLink]
    LOG_MAP --> REPLACE

    MAPPED -- No --> PASS{Already localized, non-HTTP, or skipped earlier this session?}
    PASS -- Yes --> KEEP
    PASS -- No --> PROMPT[Show Unmapped Link Found dialog]
    PROMPT --> CHOICE{User action}

    CHOICE -- Enter localized URL --> VALIDATE{Valid HTTP or HTTPS URL?}
    VALIDATE -- No --> PROMPT
    VALIDATE -- Yes --> COMMENT_MAP[Capture optional report comment]
    COMMENT_MAP --> LOCK[Acquire process-wide write lock]
    LOCK --> RELOAD[(Reload latest mapping store)]
    RELOAD --> MERGE[Merge only source URL and current target language]
    MERGE --> ATOMIC[Write temporary JSON, flush and fsync, then atomically replace store]
    ATOMIC --> PERSIST{Save succeeded?}
    PERSIST -- No --> LOG_FAIL[Log MappingSaveFailed]
    LOG_FAIL --> STOP([Stop link processing; do not start translation])
    PERSIST -- Yes --> LOG_USER[Log MappedLink and optional CommentedLink]
    LOG_USER --> REPLACE

    CHOICE -- Skip --> SESSION[Remember URL in session skip set]
    SESSION --> COMMENT_SKIP{Comment supplied?}
    COMMENT_SKIP -- Yes --> LOG_SKIP_COMMENT[Log SkippedLinkWithComment]
    COMMENT_SKIP -- No --> LOG_SKIP[Log SkippedLink]
    LOG_SKIP_COMMENT --> KEEP
    LOG_SKIP --> KEEP

    KEEP --> URL
    REPLACE --> URL
